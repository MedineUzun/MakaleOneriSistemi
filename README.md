# Article Recommendation System

A Python application that searches academic papers from Google Scholar, generates summaries, and highlights searched keywords.

## Features

- Search academic papers with keywords
- Automatic summary generation
- Keyword highlighting in results

## Technologies

- Python
- Google Scholar API
- NLP (Natural Language Processing)

## Usage

```bash
python app.py
```
